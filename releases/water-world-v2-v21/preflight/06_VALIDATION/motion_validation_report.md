# Motion Validation Report

The registry and dependency graph were generated from the V2 asset inventory and read-only AI Orb source audit. Validation checks unique element IDs, allowed motion models, parent/dependency references, explicit static entities and null unknown motion parameters. See validation_manifest.json for machine results.

Motion schema readiness is separate from asset and reference readiness. Water World fish body-part rigs and leaf-separated geometry are absent. All target rates, phases, amplitudes and frequencies remain unvalidated.

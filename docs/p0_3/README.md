# AI Orb P0-3 acceptance package

The pasted Work P0 V1.0 request is the user's task and execution authority. The uploaded ZIP supplies the frozen machine contract, schema, reference PNGs, alpha silhouette mask, and source-package checksums. This checked-in copy preserves those source bytes; derived semantic masks are in `roi_masks/` and are generated by `tools/orb-v3-generator/p0_3/generate_semantic_roi_masks.py`.

The reference images are immutable. `ROI_MASK_FREEZE_MANIFEST.json` binds each of the 12 masks to its source image SHA-256, pixel area, bounding rectangle, per-mask source overlay, and deterministic contact sheet. The material masks represent independent semantic regions and may overlap where the frozen image contains overlapping structure; validation checks and records those intersections without clipping masks to force exclusivity. The existing core silhouette remains exactly `alpha >= 8`.

Run:

```sh
python3 tools/orb-v3-generator/p0_3/generate_semantic_roi_masks.py
python3 tools/orb-v3-generator/p0_3/validate_semantic_roi_masks.py
python3 tools/orb-v3-generator/p0_3/validate_static_preflight.py
```

`P0_3_PREFLIGHT_AUDIT.md` records source-level status; the API36 workflow produces runtime PF02/PF03/PF05 evidence and updates `P0_3_PREFLIGHT_REPORT.json` only from captured run data.

The uploaded ZIP is an acceptance artifact, not an independent request to change thresholds. Its contract is frozen and is used as the machine-checkable evidence format for the user's pasted task.

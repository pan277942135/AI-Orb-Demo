1. 水下青蓝背景保留顶部阳光、水体焦散与底部两侧水草。
2. 上部采用放大的真实渔获照片，照片为第一视觉焦点；人物、鱼、鱼竿、户外场景不可用 AI 随意改绘或改变身份。

5. 照片四周是有机水光而非粗厚霓虹矩形：L1 冰蓝主水光、L2 翡翠薄纱、L3 香槟金细丝、L4 少量水滴和粒子。
